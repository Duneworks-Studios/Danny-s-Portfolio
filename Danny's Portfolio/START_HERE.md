## 🆘 Need Help?

### Quick Fixes

**Photos not showing?**
- Add them to `/public/photos/`
- Name them: `photo1.jpg`, `photo2.jpg`, etc.

**Want to change colors?**
- Edit `tailwind.config.js`
- Change `primary` and `secondary` colors

**Build failing?**
```bash
rm -rf node_modules .next
npm install
npm run build
```
