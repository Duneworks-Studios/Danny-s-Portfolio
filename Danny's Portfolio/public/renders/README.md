# 🎨 My Renders

## How to Add Your Renders

Place your 3D renders and visualizations in this directory with the following naming convention:

- `render1.jpg`
- `render2.jpg`
- `render3.png`
- etc.

### Supported Formats
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

### Tips
- Use high-quality render outputs for best results
- Recommended resolution: 1920x1080 or higher
- Images will be displayed in the "My Renders" section on the Development page

### Example
```
/public/renders/
  ├── render1.jpg
  ├── render2.jpg
  ├── render3.png
  └── render4.webp
```

Your renders will automatically appear in the gallery!
