# 📸 Photography Gallery

## How to Add Your Photos

Simply place your photos in this directory with the following naming convention:

- `photo1.jpg`
- `photo2.jpg`
- `photo3.png`
- etc.

### Supported Formats
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

### Tips
- The gallery will automatically detect and display all photos numbered 1-50
- Use high-quality images for best results
- Recommended resolution: 1920x1080 or higher
- Images will be automatically optimized by Next.js

### Example
```
/public/photos/
  ├── photo1.jpg
  ├── photo2.jpg
  ├── photo3.png
  └── photo4.webp
```

The gallery will automatically load and display all your photos with beautiful animations and a lightbox viewer!
